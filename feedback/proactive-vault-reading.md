Emile explicitly asked (2026-07-30) that vault context inform "every advice, opinion, everything" — not just questions that are obviously and directly about Duo Vert or a listed topic. He uses Claude 3-4 hours a day and wants the vault to function as real background knowledge, not something only consulted when a question happens to name a topic explicitly.

**How to apply:** the `README.md` index is always loaded automatically — that part needs no judgment. For deciding whether to *open* a specific linked file: when there's a reasonable chance it's relevant (not just when it's obviously and directly relevant), open it. Don't require a question to explicitly reference Duo Vert, a project name, or a known topic before checking — err toward checking.

**Why this is worth the extra effort:** the cost of unnecessarily opening a short topic file is small. The cost of silently giving advice that ignores something already known (a stated preference, a past decision, a confirmed fact) is worse — it undermines the entire point of building this vault, which was specifically so Emile doesn't have to re-explain context he's already given.

**Still not a license to open every file on every message regardless of topic** — a question with genuinely zero plausible connection to anything in the vault (e.g. a completely unrelated one-off factual lookup) doesn't need it. The bias is toward checking on any reasonable connection, not toward blanket loading everything unconditionally, which was rejected as inefficient — see [[duo-vert/memory-architecture]].
