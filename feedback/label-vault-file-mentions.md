When mentioning a specific vault file by name in a reply (e.g. `feedback_build_locally_not_live_browser.md`), append "(second brain)" in parentheses immediately after the filename.

**Why:** Emile said (2026-07-31) that the long snake_case/kebab-case filenames don't mean anything to him out of context — he can't tell at a glance whether a mentioned file is part of the second-brain vault or something else entirely, and has to ask each time.

**How to apply:** e.g. "Updated `feedback_build_locally_not_live_browser.md` (second brain)" — not just the bare filename, and not a vague "I saved this to memory" without naming the file. Applies to any mention of a vault file path or filename in a chat reply, whether newly written or just referenced.
